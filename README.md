# 오후 6시, 9층

선택에 따라 이야기와 엔딩이 바뀌는 **사내 로맨스 비주얼 노벨**입니다.
모바일 세로 화면용 웹게임이라 GitHub Pages에 올리면 바로 폰에서 플레이할 수 있어요.

- 공략 캐릭터 5명: 윤서아(마케팅팀 사수) · 강도윤(기획팀 팀장) · 이준호(디자인팀) · 차유진(브랜드전략팀 매니저) · 정하린(마케팅팀 선배)
- 엔딩 14개: 캐릭터별 해피/노멀 10개 + 커리어 · 솔로 · 엇갈림 · 수습 연장 엔딩
- 선택지마다 호감도가 떨어지거나 사고가 되는 "나쁜 선택"도 섞여 있고, 몇몇은 나중 장면에서 다시 돌아옴
- 캐릭터마다 전신 그림 + 업무 모드/로맨스 모드 얼굴. 표정에 따라 대사창의 얼굴이 바뀜
- 주인공 이름 입력, 호감도 알림, 자동 진행, 빨리 넘기기, 대화 기록
- 장면 일러스트 69장: 중요한 순간마다 웹툰 컷이 화면 가득 뜨고, 엔딩 화면엔 그 엔딩의 마지막 컷이 걸림
- 저장 슬롯 3개 + 자동 저장, 엔딩 앨범(힌트 포함) + 장면 일러스트 모음
- 타이틀 화면은 표지 일러스트(`img/title.webp`)
- 캐릭터는 `img/` 폴더의 그림, 배경은 코드로 그린 그림
- 홈 화면에 추가하면 앱처럼 실행, 오프라인에서도 동작(PWA)

## GitHub Pages로 배포하기

1. GitHub에서 **New repository** → 이름 예: `office-romance` → **Public**으로 생성
2. **Add file → Upload files**로 이 폴더 안의 파일을 **폴더 구조 그대로** 전부 올리기
   (`index.html`이 저장소 맨 위에 있어야 합니다)
3. 저장소 **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / 폴더: **/(root)** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/office-romance/` 에서 플레이

명령어로 올리고 싶다면:

```bash
git init
git add .
git commit -m "오후 6시, 9층 첫 배포"
git branch -M main
git remote add origin https://github.com/<아이디>/office-romance.git
git push -u origin main
```

> 배포 후 파일을 고쳤는데 폰에서 예전 버전이 보이면 `sw.js` 맨 위 `VERSION` 숫자를 올려서 다시 올리세요. (오프라인 캐시를 새로 받게 됩니다)

## 스토리 고치기 (`js/story.js`)

장면(scene)은 명령 목록입니다. 위에서부터 순서대로 실행돼요.

```js
ch1: [
  { title: '1화', sub: '점심은 누구와?' },        // 챕터 카드 (자동 저장 지점)
  { bg: 'office' },                               // 배경
  { t: '12시. 점심을 어떻게 할까?' },               // 지문
  { s: 'harin', e: 'grin', t: '돈가스래!' },        // 캐릭터 대사 + 표정
  { me: '좋아, 같이 가자!' },                       // 주인공 대사
  { choice: [
    { t: '하린 선배랑 간다', add: { harin: 2 }, go: 'ch1_harin' },
    { t: '혼자 공부한다', add: { work: 1 }, then: [
      { t: '조용한 점심이었다.' },
    ] },
  ] },
  { go: 'ch2' },                                   // 다음 장면으로
],
```

| 명령 | 뜻 |
|---|---|
| `{ bg:'office' }` | 배경 바꾸기 |
| `{ fx:'snow' }` / `'petal'` / `'none'` | 눈, 꽃잎 효과 |
| `{ title:'1화', sub:'부제' }` | 챕터 카드 |
| `{ t:'…' }` | 지문 |
| `{ me:'…' }` | 주인공 대사 |
| `{ s:'yujin', e:'smile', t:'…' }` | 캐릭터 대사. 캐릭터가 화면에 나타남 |
| `{ s:'박 부장', t:'…' }` | 그림 없는 인물 대사 |
| `{ msg:'junho', t:'…' }` | 메신저 메시지 |
| `{ sfx:'두근' }` | 웹툰 효과음 글자 ("두근", "짠!") |
| `{ outfit:{ yujin:'pt' } }` / `{ outfit:{ all:'casual' } }` | 옷 갈아입기: `work` `casual` `coat` `pt` |
| `{ show:'doyun', e:'blush' }` / `{ hide:1 }` | 캐릭터 띄우기 / 내리기 |
| `{ cg:'doyun_snow' }` / `{ cg:null }` | 장면 일러스트 띄우기 / 걷기. 배경이 바뀌거나 `hide`, 챕터 카드, 상처 주는 선택지를 고르면 자동으로 걷혀요 |
| `{ add:{ doyun:1, work:1 } }` | 호감도·업무력 올리기 |
| `{ set:{ fan:true } }` | 플래그(기억해 둘 사실) 켜기 |
| `{ if: v => v.fan, then:[…], else:[…] }` | 조건에 따라 다른 대사 |
| `{ choice:[ … ] }` | 선택지. 각 항목에 `t`, `add`, `set`, `then`, `go` |
| `{ go:'장면' }` / `{ go: v => … }` | 장면 이동 (조건 이동 가능) |
| `{ ending:'id' }` | 엔딩. `ENDINGS` 목록에 있는 id |

- 텍스트 안의 `{name}`은 플레이어 이름으로 바뀝니다. `{name|이라고|라고}`처럼 쓰면 받침에 맞는 조사를 골라 줍니다.
- 표정: `normal` `serious` `surprised` `sad` `teary` `angry` / `smile` `grin` `blush` `shy`. `img/<id>_<표정>.webp`가 있으면 그 얼굴, 없으면 업무·로맨스 모드 얼굴에 표정 기호를 얹어 보여 줘요.
  전신 그림의 얼굴과 안 맞는 표정(예: 웃는 전신인데 슬픔)이 나오면 얼굴 클로즈업 컷으로 바뀌어요.
- 배경: `dusk` `lobby` `office` `office_night` `meeting` `cafeteria` `rooftop_day` `rooftop_night` `pub` `karaoke` `street_night` `room` `hanriver` `hanriver_night` `pt`

### 장면 일러스트 추가하기

1. 그림을 `img/cg/<id>.webp`로 저장 (정사각형 500px 안팎이 가볍고 보기 좋아요)
2. `js/story.js`의 `CGS`에 `<id>: { who: 'yujin', title: '제목' }` 추가 (특정 인물 컷이 아니면 `who: null`)
3. 보여 줄 대사 바로 앞에 `{ cg:'<id>' },`
4. `node tools/check-story.js`로 모든 컷이 실제로 등장하는지 확인
   (`sw.js`는 `CGS` 목록을 자동으로 읽어서 오프라인 캐시에 넣어요. VERSION만 올려 주세요)

### 분기 규칙

- 6화가 끝나면 먼저 사고 점수 `bad`를 봐요. `BAD_LIMIT`(기본 3) 이상이면 **수습 연장 엔딩**.
- 아니면 호감도가 `ROUTE_THRESHOLD`(기본 7) 이상인 사람 중 가장 높은 사람의 루트로 들어갑니다.
- 아무도 기준을 못 넘으면 업무력 4 이상은 **커리어 엔딩**, 아니면 **솔로 엔딩**.
- 각 루트 안에서 마음이 담긴 선택을 할 때마다 `rs`가 1 오르고, 상처 주는 선택을 하면 1 내려가요.
  9화에 들어설 때 `rs`가 0보다 작으면 **엇갈림 엔딩**, 마지막 고백 때 `HAPPY_RS`(기본 2) 이상이면 해피엔딩입니다.
- 나쁜 선택은 `add`에 음수를 넣으면 돼요. 예: `add: { harin: -2, bad: 1 }`. 게임 화면에는 금 간 하트 알림이 떠요.

### 고친 뒤 검사하기

Node.js가 있으면:

```bash
node tools/check-story.js
```

여러 성향의 플레이어(무작위, 한 사람만 파는 플레이어, 일만 하는 플레이어, 사고만 치는 플레이어 …)로 24만 번쯤 플레이해서
**없는 장면으로 가는 go**, **끝나지 않는 흐름**, **도달 못 하는 엔딩**, **아무도 안 고르는 선택지**, **너무 긴 대사**를 알려 줍니다. 15초쯤 걸려요.

## 그림 바꾸기

> 상황별 옷(주말 사복·코트·PT 정장)과 표정 얼굴을 추가하는 방법은 **ART_GUIDE.md**에 정리돼 있어요. 만들 그림 목록, AI 그림 프롬프트, 배경 지우는 도구 사용법이 들어 있습니다.

캐릭터 그림은 `img/` 폴더에 있어요. **같은 파일 이름으로 덮어쓰면** 바로 바뀝니다.

| 파일 | 쓰이는 곳 |
|---|---|
| `img/<id>.webp` | 화면 가운데 서 있는 전신 (배경 투명) |
| `img/<id>_work.webp` | 업무 모드 얼굴 — 대사창, 저장 슬롯 |
| `img/<id>_love.webp` | 로맨스 모드 얼굴 — 웃거나 설렐 때, 해피 엔딩 |

`<id>`는 `seoa` `doyun` `junho` `yujin` `harin`. PNG를 쓰고 싶으면 `story.js`의 CAST에 경로를 적으세요.

```js
seoa: { …, sprite: 'img/seoa.png', faces: { work: 'img/seoa_w.png', love: 'img/seoa_l.png' } },
```

배경을 그림으로 바꾸려면:

```js
window.BG_IMAGES = { office: 'img/bg_office.jpg', pt: 'img/bg_pt.jpg' };
```

## 조작

- 화면 탭 / Space / Enter: 다음 대사
- 선택지: 탭 또는 숫자키 1~4
- 상단 버튼: 기록 · 자동 · 빨리 · 메뉴(저장, 불러오기, 호감도, 설정, 타이틀)
- 선택지 직전마다 자동 저장되니, 엔딩을 본 뒤 **이어하기**로 마지막 선택만 바꿔 다른 엔딩을 볼 수 있어요.
